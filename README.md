# AI Customer Support Platform

An AI-powered customer-support platform that businesses can integrate into their existing applications through APIs.

## Project structure

- `shopx-frontend/` — customer-side ShopX proof-of-concept
- `admin-dashboard/` — business and human-support dashboard
- `backend/` — shared FastAPI, AI, database, and integration layer

The ShopX app and admin dashboard currently use demo data so frontend work can progress independently. The shared backend will connect orders, conversations, AI responses, confidence checks, and human escalations during integration.
