# ShopX Frontend

ShopX is the customer-side proof-of-concept for the AI Customer Support Platform.

The prototype demonstrates a customer purchasing an item, viewing an order problem, opening AI support from the affected order, and receiving either an AI resolution or a human-support escalation.

## Run locally

```bash
npm install
npm run dev
```

The support responses are currently demo responses. They will be replaced with calls to the shared backend API during integration.
